# 교복 학교주관구매 길라잡이 — 연습용 웹앱

> 이 폴더는 `개발문서/`의 웹앱 설계 문서(0-1.txt, 0-2.md, 입력데이터_사전.md, 서식_인벤토리.md, ADR-002, 웹앱_prd.md 등)를 참고해
> **처음부터 새로 만든 연습용 구축**입니다. 기존 GitHub 저장소(School-Uniform-Contract)와는 무관한 별개의 결과물이며,
> git 저장소로 초기화하지 않았고 원격(GitHub)에 연결하지 않았습니다.

## 실행 방법

```bash
cd 연습/webapp
npm install
npm run dev       # http://localhost:5173 (개발)
npm run build     # 정적 빌드(dist/)
```

## 구현 범위

- 7개 화면: 홈(계약방법 4종 카드) · 계약방법 안내 · 계약절차(Stepper) · 기초자료입력(7탭) · 서식함(57종) · 내보내기 · 사용안내
- 마스터 데이터: `public/data/` 아래 fields·repeating-groups·forms(57종)·contract-methods(4종)·workflows(1인견적4/2인견적5/2단계·일반입찰11단계)
- 상태관리: 브라우저 세션 메모리만 사용(서버·DB 없음, 새로고침 시 소실) — Excel 업로드/다운로드로 보관
- PDF 출력: html2canvas + jsPDF로 미리보기 영역을 A4로 저장
- HWPX 출력: **F-019~F-025 7종만** 실제 원본 템플릿(`public/templates/`)에 `{{학교명}}`/`{{학년도}}` 토큰 치환 방식으로 생성. 나머지 50종은 원본 템플릿 파일이 이 폴더에 없어 HWPX 버튼을 노출하지 않음(PDF만 제공)
- Excel Import/Export: `xlsx` 라이브러리로 업무자료.xlsx 왕복

- 개발 서버에서 `/`, `/data/*.json`, `/templates/F-024_템플릿.hwpx` 모두 200 응답 확인

## 검증하지 못한 것 (한계, 정직하게 기록)

- **브라우저 시각 확인 미실행** — 이 세션에는 브라우저 자동화 도구가 연결되지 않아 실제 화면 렌더링·클릭 흐름은 눈으로 확인하지 못함. 개발 서버(`npm run dev`)를 열어 직접 확인 필요.
- **HWPX 50종 미연결** — 원본 매뉴얼 템플릿 파일이 없어 F-019~F-025 외에는 생성 불가. 실제 서비스로 쓰려면 나머지 템플릿 확보와 토큰 삽입 작업이 필요.
- **한컴오피스로 열어보는 수동 확인 없음** — 생성된 HWPX가 한컴에서 정상적으로 열리는지는 확인하지 못함(원본 프로젝트의 선례상 토큰 치환 방식 자체는 검증된 방식임).
- **계약방법별 서식 매핑은 추정치** — `forms.json`의 `contractMethods` 배열(특히 수의계약 쪽)은 매뉴얼 전문을 보지 못한 상태에서 합리적으로 추정한 값으로, 행정실 검토가 필요함(화면에도 "매뉴얼 확인 필요"로 표기).
- **접근성 실측 없음** — 스킵 링크·포커스 표시·시맨틱 랜드마크 등 기본기만 넣었고, 대비 수치 실측이나 키보드 전체 시나리오 완주는 하지 않음.
- **xlsx 패키지 보안 권고** — npm 레지스트리의 `xlsx@0.18.5`에는 알려진 취약점(GHSA-4r6h-8v6p-xvw6, GHSA-5pgg-2g8v-p4x9)이 있고 수정판이 없음. SheetJS 공식 CDN의 패치판 설치가 자동 승인 정책에 막혀 교체하지 못했음 — 실제 운영 전환 시 수동으로 `https://cdn.sheetjs.com/`의 최신판으로 교체 권장.
- **일괄 ZIP 출력 미구현** — 내보내기 화면에서 선택 서식을 한 번에 ZIP으로 묶는 기능은 범위에서 제외함.
- **오프라인/로컬 설치 패키징 미검증** — `npm run dev`로만 확인했고, 정적 빌드본의 오프라인 실행·exe 패키징은 시도하지 않음.
